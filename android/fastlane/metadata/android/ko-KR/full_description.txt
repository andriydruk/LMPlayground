LM Playground는 Android 기기에서 대규모 언어 모델을 직접 실행할 수 있게 해줍니다. 모델을 다운로드하고, 한 번의 탭으로 로드하고, 대화하세요 — 모두 오프라인, 모두 비공개. 클라우드 서버 없이, API 키 없이, 데이터가 기기를 떠나지 않습니다.

주요 기능

기기 내 추론 — 모든 처리가 기기에서 로컬로 이루어집니다. 대화는 비공개로 유지되며 절대 휴대폰을 떠나지 않습니다.

대화 기록 — 모든 대화가 저장되고 정리됩니다. 사이드바에서 세션을 고정, 이름 변경 또는 삭제하세요. 어떤 대화든 중단한 곳에서 바로 재개할 수 있습니다.

풍부한 채팅 경험 — 응답은 제목, 코드 블록, 목록, 굵게, 기울임꼴 등 완전한 markdown 지원으로 렌더링됩니다.

문서 — 채팅에 파일을 첨부하고 질문하세요. 기기 내 검색이 의미로 가장 관련 있는 구절을 찾아 모델에 전달하므로, 답변은 휴대폰을 벗어나지 않는 문서에서 바로 나옵니다. PDF, Word, EPUB, HTML, Markdown, 일반 텍스트를 지원하며, 작은 임베딩 모델을 처음 한 번만 내려받습니다.

Vision — 사진을 보내고 사진에 대해 대화하세요. 갤러리에서 이미지를 첨부하거나 카메라로 촬영한 다음, 모델에게 무엇이 보이는지 물어보세요: 장면 설명, 사물 인식, 사진 속 텍스트 읽기 등이 가능합니다. Gemma, Qwen, Ministral 비전 모델을 지원하며, 이미지는 사용자의 기기에서 바로 이해됩니다.

추론 모델 — DeepSeek R1, Nemotron, LFM2.5 Thinking과 같은 모델의 사고 과정을 조절 가능한 사고 예산과 함께 스타일링된 접을 수 있는 섹션에서 확인하세요.

도구 — 성능이 뛰어난 모델은 답변 안에서 바로 웹을 검색하고, 페이지를 가져오고, JavaScript를 실행할 수 있습니다. 각 도구는 기본적으로 꺼져 있으며, 설정 → 도구에서 모델별로 원하는 것만 켜면 됩니다. 웹 검색과 가져오기는 켰을 때만 인터넷에 연결되며 — 그 외 모든 것은 기기에 그대로 남습니다.

백그라운드 생성 — 답변 생성을 시작한 뒤 앱을 떠나도 계속 실행됩니다. 실시간 알림이 생성 상태와 토큰 수를 표시하고, 앱을 다시 열지 않고도 결과를 복사하거나 공유할 수 있으며, 완료되면 알림음이 울립니다.

생성 속도 추적 — 모든 응답의 토큰 수, 생성 시간, tok/s 속도를 확인하세요.

모델별 매개변수 — 각 모델이 자체 생성 설정을 기억합니다. 컨텍스트 크기, 사고 예산, 온도, Top-P, Top-K, Min-P, 반복 페널티, 시드를 세밀하게 조정하세요.

시스템 프롬프트 — 재사용 가능한 지침을 한 번만 저장하고 어떤 모델에든 적합한 것을 선택하세요. 톤, 역할 또는 출력 형식을 세션 전반에 걸쳐 일관되게 유지합니다.

커스텀 모델 — 내장 카탈로그와 함께 어떤 소스에서든 자체 GGUF 모델 파일을 로드하세요.

안정적인 다운로드 — 진행 알림, 속도 및 예상 시간 표시, 네트워크 중단 시 자동 재개 기능이 있는 맞춤 다운로드 엔진.

유연한 저장소 — Android의 Storage Access Framework를 사용하여 수 GB의 모델 파일을 저장할 위치를 선택하세요. 위치 간 모델을 쉽게 이동할 수 있습니다.

최적화된 성능 — arm64 기기에서 더 빠른 생성을 위해 KleidiAI 커널과 OpenMP로 ARM에 최적화되었습니다.

지원 모델

• Qwen 3.5 (0.8B, 2B, 4B) — Alibaba
• Gemma 4 (E2B, E4B) — Google
• GPT-OSS 20B — OpenAI
• Nemotron 3 Nano (4B) — NVIDIA
• Granite 4.0 (Micro, H-Tiny) — IBM
• DeepSeek R1 Distill (1.5B, 7B) — DeepSeek
• Phi-4 mini (3.8B) — Microsoft
• LFM2.5 (350M, 1.2B Thinking) — Liquid AI
• Ministral 3 (3B, 8B — Instruct & Reasoning) — Mistral
• Llama 3.2 (1B, 3B) — Meta

가장 작은 모델은 267 MB부터 시작합니다. 큰 모델(4B–8B)은 8GB 이상의 RAM이 권장되며, 20B 모델은 메모리가 넉넉한 고급 기기가 필요합니다. 커스텀 GGUF 모델도 로드할 수 있습니다.

오픈 소스

LM Playground는 MIT 라이선스의 오픈 소스입니다. Hugging Face의 모델과 함께 llama.cpp로 구동됩니다.
