LM Playground ช่วยให้คุณเรียกใช้โมเดลภาษาขนาดใหญ่ได้โดยตรงบนอุปกรณ์ Android ของคุณ ดาวน์โหลดโมเดล โหลดด้วยการแตะเพียงครั้งเดียว และสนทนาได้ทันที — ทั้งหมดแบบออฟไลน์ เป็นส่วนตัวโดยสมบูรณ์ ไม่มีเซิร์ฟเวอร์คลาวด์ ไม่มี API key ไม่มีข้อมูลใดออกจากอุปกรณ์ของคุณ

คุณสมบัติเด่น

การประมวลผลบนอุปกรณ์ — การประมวลผลทั้งหมดเกิดขึ้นภายในอุปกรณ์ของคุณ บทสนทนาของคุณเป็นส่วนตัวและไม่เคยออกจากโทรศัพท์ของคุณ

ประวัติการสนทนา — บทสนทนาทั้งหมดของคุณจะถูกบันทึกและจัดระเบียบไว้ ปักหมุด เปลี่ยนชื่อ หรือลบเซสชันจากแถบด้านข้าง สนทนาต่อจากที่ค้างไว้ได้ทุกเมื่อ

ประสบการณ์แชทที่สมบูรณ์ — การตอบกลับแสดงผลพร้อมรองรับ Markdown เต็มรูปแบบ รวมถึงหัวข้อ บล็อกโค้ด รายการ ตัวหนา ตัวเอียง และอื่นๆ อีกมากมาย

เอกสาร — แนบไฟล์เข้ากับแชตแล้วถามคำถามเกี่ยวกับมัน การค้นหาบนอุปกรณ์จะหาย่อหน้าที่เกี่ยวข้องมากที่สุดตามความหมายแล้วส่งให้โมเดล คำตอบจึงมาจากเอกสารของคุณโดยตรง ซึ่งไม่เคยออกจากโทรศัพท์ รองรับ PDF, Word, EPUB, HTML, Markdown และข้อความธรรมดา โมเดล embedding ขนาดเล็กจะดาวน์โหลดครั้งเดียวตอนใช้ครั้งแรก

วิทัศน์ — ส่งรูปภาพและแชทเกี่ยวกับมัน แนบรูปจากแกลเลอรีหรือถ่ายด้วยกล้อง แล้วถามโมเดลว่าเห็นอะไร: บรรยายฉาก ระบุวัตถุ หรืออ่านข้อความ ใช้ได้กับโมเดลวิทัศน์ Gemma, Qwen และ Ministral และรูปภาพจะถูกเข้าใจบนอุปกรณ์ของคุณโดยตรง

โมเดลการให้เหตุผล — ดูกระบวนการคิดของโมเดลอย่าง DeepSeek R1, Nemotron และ LFM2.5 Thinking ที่แสดงในส่วนที่จัดสไตล์พับเก็บได้พร้อมงบประมาณการคิดที่ปรับได้

เครื่องมือ — โมเดลที่มีความสามารถสามารถค้นหาเว็บ ดึงหน้าเว็บ และรัน JavaScript ได้ทันทีภายในการตอบกลับ เครื่องมือแต่ละอย่างปิดอยู่ตามค่าเริ่มต้น เปิดเฉพาะที่คุณต้องการแยกตามโมเดลได้ใน การตั้งค่า → เครื่องมือ การค้นหาเว็บและการดึงหน้าเว็บจะเชื่อมต่ออินเทอร์เน็ตเฉพาะเมื่อคุณเปิดใช้งานเท่านั้น — ส่วนที่เหลือทั้งหมดยังคงอยู่บนอุปกรณ์ของคุณ

การสร้างในเบื้องหลัง — เริ่มการตอบกลับ แล้วออกจากแอป โดยที่มันยังคงทำงานต่อไป การแจ้งเตือนแบบสดจะแสดงสถานะการสร้างและจำนวนโทเคน ให้คุณคัดลอกหรือแชร์ผลลัพธ์ได้โดยไม่ต้องเปิดแอปขึ้นมาใหม่ และส่งเสียงเตือนเมื่อเสร็จสิ้น

การติดตามความเร็วในการสร้าง — ดูจำนวนโทเคน เวลาในการสร้าง และความเร็ว tok/s สำหรับทุกการตอบกลับ

พารามิเตอร์แยกตามโมเดล — แต่ละโมเดลจะจดจำการตั้งค่าการสร้างของตัวเอง ปรับขนาดบริบท งบประมาณการคิด อุณหภูมิ Top-P, Top-K, Min-P ค่าลงโทษการซ้ำ และ seed

พรอมต์ระบบ — บันทึกคำสั่งที่ใช้ซ้ำได้เพียงครั้งเดียวและเลือกใช้ที่เหมาะสมกับโมเดลใดก็ได้ รักษาโทน บทบาท หรือรูปแบบผลลัพธ์ให้สอดคล้องกันในทุกเซสชัน

โมเดลแบบกำหนดเอง — โหลดไฟล์โมเดล GGUF ของคุณเองจากแหล่งใดก็ได้ควบคู่ไปกับแคตตาล็อกในตัว

การดาวน์โหลดที่เชื่อถือได้ — เอ็นจินดาวน์โหลดแบบกำหนดเองพร้อมการแจ้งเตือนความคืบหน้า แสดงความเร็วและเวลาที่เหลือ และดำเนินการต่ออัตโนมัติเมื่อเครือข่ายขัดข้อง

พื้นที่จัดเก็บแบบยืดหยุ่น — เลือกตำแหน่งจัดเก็บไฟล์โมเดลขนาดหลาย GB ด้วย Storage Access Framework ของ Android ย้ายโมเดลระหว่างตำแหน่งได้อย่างง่ายดาย

ประสิทธิภาพที่เพิ่มประสิทธิภาพ — ปรับแต่งสำหรับ ARM ด้วย KleidiAI kernels และ OpenMP เพื่อการสร้างที่เร็วขึ้นบนอุปกรณ์ arm64

• GPT-OSS 20B — OpenAI
• Nemotron 3 Nano (4B) — NVIDIA
• Granite 4.0 (Micro, H-Tiny) — IBM
• DeepSeek R1 Distill (1.5B, 7B) — DeepSeek
• Phi-4 mini (3.8B) — Microsoft
• LFM2.5 (350M, 1.2B Thinking) — Liquid AI
• Ministral 3 (3B, 8B — Instruct & Reasoning) — Mistral
• Llama 3.2 (1B, 3B) — Meta

เริ่มต้นที่เพียง 267 MB สำหรับโมเดลที่เล็กที่สุด โมเดลขนาดใหญ่ (4B–8B) ทำงานได้ดีกับ RAM 8+ GB และโมเดล 20B ต้องใช้อุปกรณ์ระดับไฮเอนด์ที่มีหน่วยความจำมากเพียงพอ คุณยังสามารถโหลดโมเดล GGUF แบบกำหนดเองได้อีกด้วย
