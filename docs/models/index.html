Open models picked and tuned for phones. Each one runs entirely on your device — download it once and it works offline from then on.

Downloads are Hugging Face downloads of each model’s GGUF files over the last 30 days (checked November 21, 2026).

Bring your own

Don’t see your favorite?
Load any GGUF.

The chat template and tokenizer are read straight from the file, so most GGUF models just work. If one doesn’t, tell us on GitHub

  1. iPhone and iPadTap Import in Settings → Models, or copy the file into the app’s Models folder in Files.
  2. AndroidPut the .gguf file in the folder chosen in Settings → Models. It shows up next to the built-in models.
  3. Start chattingPick it from the model selector like any other model.
