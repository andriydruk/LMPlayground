Why on-device

Private by construction. Fast by design.

The model weights live on your phone. Prompts, drafts and answers never touch a server — there isn't one to touch.

01

Fully offline

Airplane mode? Subway? Flight? No difference. Inference happens on your SoC, never on someone else's server.

02

Your roles, saved

Save reusable system prompts once and pick the right one for any model. Keep tone, role and output format consistent across every session.

03

Tune every knob

Temperature, Top-P, Top-K, Min-P, repetition penalty, seed, context size — each model remembers its own settings.

04

Save anywhere

Models are multi-gigabyte. Download them to any folder — internal storage, SD card, or an external drive. Move them between locations any time.

Documents

Ask your files.
Not the cloud.

Attach a document to a chat and ask questions about it. The app finds the relevant passages and hands them to the model — everything happens on your phone, so the file never leaves it.

Bring any file

PDF, Word, EPUB, HTML, Markdown or plain text — attach it like a photo and it's ready to question.

pdf / docx / epub → attach

Search by meaning

Your question is matched against the document by meaning, not keywords, so the model answers from the right passages.

question → passages

Stays on device

Indexing and search run locally, in any of the app's 28 languages — nothing is uploaded, ever.

0 → uploads
Document search downloads a small embedding model once (EmbeddingGemma, 278 MB) — after that it works offline with every chat model.

Tools

Let capable models
take real actions.

Turn on tools and a capable model can act mid-reply — run a calculation, search the web, or read a page — then use the result in its answer. Everything runs on your phone.

Run JavaScript

Runs JavaScript in a secure sandbox for math, dates, and text processing. No internet or file access.

(2 + 3) × 4 → 20

Web search

Searches the web and returns result titles, links, and snippets so the model can find current information.

"Pixel 9 reviews" → 5 results

Fetch web page

Opens a link and reads its main content as text so the model can summarize or quote a page.

example.com → markdown
Tools let capable models take actions during a reply, like searching the web or running a calculation. Each tool is off by default — turn on only the ones you want. Tools work only with models that support them (look for the hammer badge).
