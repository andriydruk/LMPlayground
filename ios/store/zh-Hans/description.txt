LM Playground 直接在你的 iPhone 和 iPad 上运行大型语言模型。下载模型，轻点一下即可加载，然后开始对话——私密地在你的设备上完成。无需云服务器，无需 API 密钥，无需账户，数据不会离开你的设备。

主要功能

设备端推理——每条回复都在你的 iPhone 或 iPad 上通过 Metal 本地生成。你的对话始终保持私密。

聊天记录——对话会被保存和整理。你可以置顶、重命名或删除对话，并从上次停下的地方继续任何聊天。在 iPad 上，聊天列表位于对话旁边的边栏中。

丰富的回复——回答以完整的 Markdown 呈现：标题、带复制按钮的代码块、列表、表格、粗体和斜体。

文档——在聊天中附加文件，然后就文件内容提问。设备端搜索会按语义找到最相关的段落并交给模型，因此回答直接来自你的文档，而文档永远不会离开你的设备。支持 PDF、Word、EPUB、HTML、Markdown 和纯文本；首次使用时会一次性下载一个小型嵌入模型。

视觉——发送照片并围绕它聊天。从图库中选择图片或用相机拍摄，然后问模型看到了什么：描述场景、识别物体或读取文字。图片直接在你的设备上理解。

语音输入——轻点麦克风开始说话，文字会随着你说话实时出现，支持 35 种语言。语音在设备上识别，绝不会被保存或发送。

推理模型——在可折叠区域中查看推理模型的思考过程，并可调整思考预算。

工具——能力较强的模型可以在回复过程中搜索网页、阅读网页，并在沙盒中运行 JavaScript。所有工具默认关闭，你可以按模型只开启需要的工具。网页搜索和网页阅读只有在你开启后才会访问互联网。

速度一目了然——每条回复都会显示 token 数量和每秒 token 数。

按聊天设置——上下文大小、思考预算、温度、Top-P、Top-K、Min-P、重复惩罚和随机种子。

系统提示词——保存一次可复用的指令，即可搭配任何模型使用，让语气、角色或输出格式保持一致。

自定义模型——除内置目录外，还可以从“文件” App 导入你自己的 GGUF 模型。

可靠的下载——模型在后台下载，显示进度、速度和剩余时间，网络中断后会自动续传。

模型

一个在 iPhone 和 iPad 上测试过的模型目录，涵盖 Qwen、Gemma、Llama、LFM、Granite 等，最小只有几百 MB。加载模型前，App 会检查可用内存，并在模型对你的设备来说过大时提醒你。

开源

LM Playground 基于 MIT 许可证开源。由 llama.cpp 驱动，模型来自 Hugging Face。
