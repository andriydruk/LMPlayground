LM Playground는 대규모 언어 모델을 iPhone과 iPad에서 직접 실행합니다. 모델을 다운로드하고, 한 번의 탭으로 로드한 뒤 대화하세요. 모두 비공개로, 내 기기에서 이루어집니다. 클라우드 서버, API 키, 계정이 필요 없으며 데이터가 기기를 떠나지 않습니다.

주요 기능

기기 내 추론 — 모든 답변은 iPhone 또는 iPad에서 Metal로 로컬 생성됩니다. 대화는 비공개로 유지됩니다.

대화 기록 — 대화가 저장되고 정리됩니다. 고정하거나 이름을 바꾸거나 삭제할 수 있고, 어떤 채팅이든 멈춘 곳에서 바로 이어갈 수 있습니다. iPad에서는 대화 옆 사이드바에 채팅 목록이 표시됩니다.

풍부한 답변 — 답변은 완전한 Markdown으로 표시됩니다. 제목, 복사 버튼이 있는 코드 블록, 목록, 표, 굵게, 기울임꼴을 지원합니다.

문서 — 채팅에 파일을 첨부하고 그 내용에 대해 질문하세요. 기기 내 검색이 의미를 기준으로 가장 관련성 높은 부분을 찾아 모델에 전달하므로, 답변은 문서에서 바로 나옵니다. 문서는 기기를 떠나지 않습니다. PDF, Word, EPUB, HTML, Markdown, 일반 텍스트를 지원하며, 작은 임베딩 모델이 처음 사용할 때 한 번만 다운로드됩니다.

Vision — 사진을 보내고 그 사진에 대해 대화하세요. 보관함에서 이미지를 고르거나 카메라로 찍은 뒤 모델에게 무엇이 보이는지 물어보세요. 장면을 설명하고, 사물을 식별하고, 글자를 읽을 수 있습니다. 이미지는 기기에서 바로 분석됩니다.

음성 받아쓰기 — 마이크를 탭하고 말하면 말하는 동안 글자가 나타납니다. 35개 언어를 지원합니다. 음성은 기기에서 인식되며 저장되거나 전송되지 않습니다.

추론 모델 — 추론 모델의 사고 과정을 접을 수 있는 섹션에서 확인하고, 사고 예산을 조절할 수 있습니다.

도구 — 지원 모델은 답변 중에 웹 검색, 페이지 읽기, 샌드박스에서 JavaScript 실행을 할 수 있습니다. 모든 도구는 기본적으로 꺼져 있으며, 원하는 도구만 모델별로 켤 수 있습니다. 웹 검색과 페이지 읽기는 켰을 때만 인터넷에 접속합니다.

한눈에 보는 속도 — 답변마다 토큰 수와 초당 토큰 수를 확인하세요.

채팅별 설정 — 컨텍스트 크기, 사고 예산, Temperature, Top-P, Top-K, Min-P, 반복 페널티, 시드.

시스템 프롬프트 — 재사용할 지침을 한 번 저장하고 어떤 모델에서든 사용해 어조, 역할, 출력 형식을 일관되게 유지하세요.

커스텀 모델 — 기본 제공 카탈로그와 함께, 파일 앱에서 직접 가진 GGUF 모델을 가져올 수 있습니다.

안정적인 다운로드 — 모델은 진행률, 속도, 남은 시간을 표시하며 백그라운드에서 다운로드되고, 네트워크가 끊겨도 이어서 받습니다.

모델

iPhone과 iPad에서 테스트한 모델 카탈로그로, Qwen, Gemma, Llama, LFM, Granite 등 수백 메가바이트 크기부터 제공합니다. 앱은 모델을 로드하기 전에 여유 메모리를 확인하고, 모델이 기기에 비해 너무 크면 알려 줍니다.

오픈 소스

LM Playground는 MIT 라이선스의 오픈 소스입니다. llama.cpp로 구동되며, 모델은 Hugging Face에서 제공됩니다.
