LM Playground は、大規模言語モデルを iPhone と iPad 上で直接実行できるアプリです。モデルをダウンロードし、ワンタップで読み込んでチャット。すべてプライベートに、あなたの端末内で動作します。クラウドサーバー、APIキー、アカウントは不要で、データが端末の外に出ることはありません。

主な機能

端末内での推論 — すべての返答は、iPhone または iPad 上で Metal を使ってローカルに生成されます。会話はプライベートなままです。

チャット履歴 — 会話は保存・整理されます。ピン留め、名前の変更、削除ができ、どのチャットも中断したところから再開できます。iPad では、会話の横のサイドバーにチャットが並びます。

リッチな返答 — 回答は Markdown で表示されます。見出し、コピーボタン付きのコードブロック、リスト、表、太字、斜体に対応しています。

ドキュメント — チャットにファイルを添付して、その内容について質問できます。端末内の検索が意味に基づいて最も関連性の高い箇所を見つけてモデルに渡すため、回答はドキュメントそのものから得られます。ドキュメントが端末の外に出ることはありません。PDF、Word、EPUB、HTML、Markdown、プレーンテキストに対応。小さな埋め込みモデルが初回使用時に一度だけダウンロードされます。

Vision — 写真を送って、その写真についてチャットできます。ライブラリから画像を選ぶかカメラで撮影し、何が見えるかをモデルに尋ねてみましょう。情景の説明、物体の識別、文字の読み取りができます。画像は端末内で解析されます。

音声入力 — マイクをタップして話すと、話している間に言葉が表示されます。35言語に対応。音声は端末内で認識され、保存や送信されることはありません。

推論モデル — 推論モデルの思考過程を折りたたみ可能なセクションで確認でき、思考バジェットも調整できます。

ツール — 対応モデルは、返答中に Web 検索、ページの読み取り、サンドボックス内での JavaScript 実行を行えます。各ツールは初期設定でオフになっており、使いたいものだけをモデルごとにオンにできます。Web 検索とページ読み取りがインターネットにアクセスするのは、オンにしたときだけです。

速度をひと目で — 返答ごとにトークン数と1秒あたりのトークン数を表示します。

チャットごとの設定 — コンテキストサイズ、思考バジェット、Temperature、Top-P、Top-K、Min-P、繰り返しペナルティ、シード。

システムプロンプト — 再利用できる指示を一度保存すれば、どのモデルでも使えます。口調、役割、出力形式を一定に保てます。

カスタムモデル — 内蔵カタログに加え、「ファイル」App から独自の GGUF モデルを読み込めます。

確実なダウンロード — モデルはバックグラウンドでダウンロードされ、進捗、速度、残り時間を表示。ネットワークが途切れても再開します。

モデル

iPhone と iPad でテスト済みのモデルのカタログ。Qwen、Gemma、Llama、LFM、Granite などのモデルを、数百メガバイトのサイズから用意しています。モデルを読み込む前に空きメモリを確認し、端末に対して大きすぎる場合はお知らせします。
